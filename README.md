# Análisis de videojuegos | Proyecto TripleTen

## Descripción del proyecto

Este proyecto forma parte de mi formación en Data Science con TripleTen. El objetivo es analizar datos históricos de videojuegos para identificar patrones de ventas, comparar plataformas y géneros, y estudiar las diferencias en las calificaciones de los usuarios.

## Objetivos

- Explorar y preparar los datos para el análisis.
- Analizar las ventas por plataforma, género y región.
- Identificar patrones y tendencias del mercado.
- Comparar las calificaciones de los usuarios.
- Formular y contrastar hipótesis mediante pruebas estadísticas.
- Interpretar los resultados para obtener conclusiones basadas en datos.

## Herramientas y tecnologías

- Python
- Pandas
- NumPy
- Matplotlib
- SciPy
- Jupyter Notebook

## Análisis realizado

Se desarrollan análisis exploratorios, comparaciones estadísticas y visualizaciones para comprender el comportamiento de las ventas y las calificaciones de los videojuegos.

## Aprendizajes

Este proyecto me permite fortalecer mis habilidades en programación con Python, manipulación de datos, estadística, pruebas de hipótesis y comunicación de resultados.
